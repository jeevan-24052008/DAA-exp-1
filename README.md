This project compares **Interpolation Search** and **Binary Search**.

### What it does

- Accepts a sorted list of integers and a target number.
- Searches for the target using both algorithms.
- Shows the index where the target is found.
- Shows the number of comparisons and execution time.
- Includes a performance analysis for larger input sizes.

### Input format

- Array: comma-separated sorted numbers, such as `2, 5, 10, 15, 23`
- Target: a single integer, such as `23`

### Important note

The array must be sorted in ascending order for both search algorithms to work correctly.
